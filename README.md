# 🎮 Tic Tac Toe

A modern and responsive Tic Tac Toe game built with **React** and **CSS**.
The project combines classic gameplay with a clean glassmorphism-inspired interface, animations, score tracking, and responsive design.

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/Er-Debabrata/Tic-Tac-Toe-.git
```

Go to the project folder:

```bash
cd tic-tac-toe
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in the terminal.

## 🎮 How to Play

1. Player X starts the game.
2. Players take turns selecting an empty cell.
3. The first player to get three matching symbols in a row, column, or diagonal wins.
4. If all cells are filled without a winner, the game ends in a draw.
5. Use **Play Again** to start another round.
6. Use **Reset Score** to clear the scoreboard.
